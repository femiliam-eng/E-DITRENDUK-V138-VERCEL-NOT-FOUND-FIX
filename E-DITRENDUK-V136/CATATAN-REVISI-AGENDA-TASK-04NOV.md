# Revisi Agenda Kegiatan dan Task Deadline

- Urutan tanggal menggunakan nilai tanggal kronologis, mendukung ISO dan format DD/MM/YYYY.
- Filter status Task Deadline tetap **Semua / Done / Not yet**.
- Validasi ekstensi lampiran Agenda sebelum pengiriman ke API.
- Tombol unggah lampiran dan simpan formulir dicegah dari pengiriman ganda saat proses berlangsung.
- Kolom Hasil Kegiatan Agenda tetap ditampilkan.

Belum diuji pada PostgreSQL aktif; pengujian di sini adalah sintaks dan kontrak frontend.
